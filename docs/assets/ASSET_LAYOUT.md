# Asset layout

`game/assets/` is ENTER M's single shared asset root. New project-wide runtime
art, audio, fonts, and GUI files belong here; do not recreate the retired
`game/assets/images/`, `game/images/`, `game/gui/`, `game/bgm/`, `game/sfx/`,
or `game/mod_assets/` trees.

| Content | Runtime directory |
|---|---|
| Backgrounds and CGs | `game/assets/backgrounds/`, `game/assets/cg/` |
| Character sprites and MPT art | `game/assets/characters/`, `game/assets/mpt/` |
| Music and sound effects | `game/assets/audio/bgm/`, `game/assets/audio/sfx/` |
| Base and ENTER M GUI | `game/assets/gui/`, `game/assets/gui/` |
| Fonts | `game/assets/fonts/` |
| Bullets, transitions, emoji, and miscellaneous art | `game/assets/bullets/`, `game/assets/transitions/`, `game/assets/emoji/`, `game/assets/misc/` |
| Working/unsorted art | `game/assets/dump/` |
| Non-shipping source material | `game/assets/archive/` |

Project-wide Ren'Py declarations live separately in
`game/asset_definitions/`. Runtime paths are relative to `game/`, so a sprite
declaration uses `assets/characters/...`, not `game/assets/characters/...`.
`game/options.rpy` disables automatic basename image discovery because runtime
art is explicitly declared across category-specific directories. It retains
`assets/` as the compatibility search prefix for GUI paths generated by Ren'Py
itself.

The archive subtree is excluded from release builds. Add-ons that own their
files remain self-contained under `game/addons/`; the imported Mika Lost Record
likewise keeps its vendor-internal tree under `game/lost_records/Mika/`.
Packaging icons (`icon.ico` and `icon.icns`) remain at the project root because
Ren'Py's build tooling consumes them there.

CG Gallery and Music Room retain explicitly labelled pre-consolidation paths
only as persistent identity keys. They are not live file references; changing
them would relock existing gallery and soundtrack progress.

Run the static consolidation check with:

```text
python tools/audit_asset_paths.py
```

The checker verifies concrete paths and exact casing, rejects live references
to retired roots, and reports the two known missing pointing-arm files in the
imported Natsuki MPT pack as warnings.
