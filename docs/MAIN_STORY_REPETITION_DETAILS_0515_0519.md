## Labels

- **P1 — structural/high:** repeated material noticeably delays change, repeats a reveal, or tells the reader how to interpret a scene that already landed.
- **P2 — local/medium:** a joke, reaction, metaphor, or explanation runs one beat too long.
- **P3 — polish/low:** close word reuse, filler, or a repeated sentence frame worth varying during line edit.
- **KEEP:** the repetition is load-bearing, ritualistic, character-specific, or a useful motif. Usually the recommendation is to trim captions around it, not the recurrence itself.
- **NEW:** no current inline annotation verifiably identifies this target.
- **ALREADY ANNOTATED:** a current inline comment identifies essentially the same problem.
- **PARTLY ANNOTATED:** a nearby/broader comment catches the scene or principle, but not the more granular repetition identified here.
- **STALE/ADDRESSED:** the annotation describes prose no longer present in this snapshot.
