# Legacy Tsubaki boss sprites

These are the original static, black-backed Tsubaki-mode boss sprites that
shipped before the progressive animated refresh. They remain here as source
history and are not referenced by the live fight.

- `phase1_legacy.png` - original phase-one sprite with the retired ponytail.
- `phase2_legacy.png` - original phase-two exhausted pose.

The high-resolution sources for the replacement set are preserved separately
under `docs/archive/tsubaki-boss/`, outside the release build.
